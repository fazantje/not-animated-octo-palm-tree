# Tool Feedback

Append-only log of tool frictions, surprises, and missing features the
restructure-intents agent noticed while working. The human reads this between
sessions and adjusts the tools accordingly — closing the loop.

Only log what was painful or surprising. Skip routine successes.

Entry format:
```markdown
## YYYY-MM-DD — <tool_name>
**What I tried**: exact command
**What happened**: the error / unexpected behavior
**What I expected**: what I thought should happen
**Workaround** (if any): what I did instead
```
